IOTProject - 物联网后端 Demo
**当前版本**: v1.0.1  
**最后更新**: 2026-01-31  
 **状态**: 基础架构开发完成 / 设备模块规划中
🛠️ 用的什么技术？
**Web**: Gin (高性能路由)
**数据库**: PostgreSQL (pgx 连接池)
**缓存**: Redis (分布式锁、JWT 黑名单、单点登录)
**安全**: JWT 鉴权 + Bcrypt 密码哈希

🛠这是一个基于 Go + Gin 实现的物联网管理系统后端。虽然目前还在开发中，但已经搭建好了非常稳健的基础架构。
用的什么技术？
Web: Gin (快、好用)
  数据库: PostgreSQL (存用户和设备)
  缓存: Redis (处理登录态、黑名单、注册频率限制)
  安全: JWT 鉴权 + Bcrypt 密码加密
  ✨现在能用的功能
1.用户模块: 支持注册、登录、获取用户信息、退出登录。
2.安全防护:
    注册时有 Redis 锁，防止短时间内重复注册。
    支持单点登录（新设备登录会挤掉旧设备）。
    自带黑名单，点下注销 Token 立即失效。
3.开发友好:
    统一返回: 所有接口都是 {code, data, msg} 这种格式。
    自动报错: 只要在业务里写 return error_code.UserExists，前端就能收到正确的 HTTP 状态码。
🚀 怎么跑起来？
1.克隆项目到本地。
2.创建 .env 文件（参考本地配置），填入你的数据库和 Redis 密码。
3.运行 go run main.go。
